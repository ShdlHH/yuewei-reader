Verdict

不是换皮，是把工具收进书里

Ui.java 里已经有 20 / 16 / 8 的间距、14 的卡片圆角、12 / 14 / 16 / 17 / 22 的字号， 说明移动端并不缺令牌；缺的是每一屏只讲一件事的排序。阅读页最接近提案， 书架与设置仍像 Android 默认表单，搜索与书源停在「结果列表 + Toast」。

01 · 已对齐

材料

三套 Ui.Palette、页面 / 列表 / 卡片间距、14/12/10/22 圆角、宋体正文、2dp 章节滑杆与浮层位移曲线，都已经和《视觉升级方案》同一套语言。

02 · 仍偏离

结构

书架把「阅微」当页面标题、四个等宽胶囊抢焦点；阅读顶栏没有章节、底栏符号与文字混排；设置两个保存入口；搜索 / 书源仍是系统列表的换色版。

03 · 判断

一屏一事

手机没有并排空间，页头、主对象、工具必须形成 1 : 2 : 1 的层级。令牌再准，若第一眼落在四个按钮上，读起来仍然是工具页。

Rules

跨屏规则：把「书」的秩序写死

六屏各自修完之后，还需要同一套规则兜底，否则下一轮又会分叉。 以下九条可直接落到 Ui.java 的常量与各页的 build 方法里。

组件统一规则
页头44dp 返回热区 + 22sp 页面标题 + 右侧最多一个动作；标题下只允许一行 11sp 说明。页面左右统一 20dp，书架页例外地把印章放在标题左侧。
主对象每屏只允许一个朱砂实色动作：书架 = 导入 TXT，搜索 = 搜索，书源 = 导入 JSON，设置 = 完成。其余全部为「卡片底 + 1px 界线 + 胶囊」。
列表行行高 ≥ 56dp；左序号 28dp / 主标题 16sp / meta 11sp / 右状态 10.5sp；行间 1px line-soft，左侧缩进 28dp。
触控所有可点区域 ≥ 44 × 44dp；滑杆 thumb ≥ 12dp + 4dp 光晕；图标统一 20px 线性，不再混用字族符号。
浮层一律底部 sheet：上圆角 16dp、grabber 32 × 3、最大高 78%；危险动作赭色 + 二次确认，不再使用系统 AlertDialog 列表。
安全区状态栏 / 开孔 / 手势区全部用窗口级 inset；阅读页底部 ≥ 20dp + 6dp；设置粘性保存条同样避让。
字号页面 22 / 书名 17 / 行 16 / 分组 12 / 正文 14 / 提示 12 / meta 10.5；标题字距 +.04–.06em，正文不加。
主题三套 Ui.Palette 必须覆盖对话框、Toast、系统栏；切换主题不得重建 Activity，阅读页现有 applyTheme 已是正确做法。
动效浮层 380 / 420ms、cubic-bezier(.22,.8,.24,1)，页脚 200ms 淡出；不做缩放、不做重排，系统「减少动画」时直接切换。
Priority

先修第一眼，再统一结构

P0 决定这套界面能不能被认成「一本书」；P1 决定它有没有「口袋本」的顺手； P2 只做精修，不改变结论。

P0 · 气质

先做三件

  1. 阅读页顶栏加章节、底栏分两行、页脚加字距；补一次性「轻点中间」提示。
  2. 书架页头改为「书架」+ 同步状态；动作 4 → 3，设置改 44dp 圆形图标。
  3. 设置合并保存入口，主题改三色分段器；先做视觉，再改保存逻辑。
P1 · 结构

再统一三处

  1. 目录 / 排版 AlertDialog → 底部 sheet；目录加序号与「在读」。
  2. 搜索三态（搜索中 / 无书源 / 无结果）+ 结果行「加入 / 已加入」。
  3. 书源行加状态点与启用、说明收一行；空状态与搜索共用。
P2 · 精修

最后统一

  1. 四个面板图标换 20px 线性；滑杆 / 复选框 / 输入框高度归一。
  2. 书目行加 2dp 细进度线；空状态印章。
  3. 三主题对比度校准（夜间 muted 对 bg ≥ 4.5:1），截图验收。

令牌 Ui.java Palette 三主题、SPACE_PAGE / LIST / CARD、TEXT_*、RADIUS_CARD / ROW / INPUT / PILL；新增 sheet 圆角、图标尺寸与触控最小高度常量。
