## 三、数据模型与迁移

### 3.1 `book` 表新增列（`Db.init` 内以现有 `ensureColumn` 幂等添加）

| 列 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `new_chapters` | INTEGER | 0 | 上次检查发现的新增章节数，>0 表示「有更新」 |
| `toc_checked_at` | TEXT | NULL | 上次检查目录的时间（ISO-8601），用于间隔判断与「上次检查」展示 |

- 迁移方式：复用 `Db.ensureColumn(c, "book", ...)`，老库启动自动补齐，重复执行无副作用。
- 不改 `chapter`、`reading_progress`、`download_task`、`book_source`、`setting` 结构。

### 3.2 `setting` 表新增键（无 DDL，键值存储）

| 键 | 默认值 | 说明 |
|---|---|---|
| `update.check.enabled` | `true` | 启动后是否自动检查更新 |
| `update.check.intervalMin` | `60` | 检查间隔（30 / 60 / 0=仅手动） |
| `update.check.lastAt` | 空 | 上一轮检查完成时间 |
| `shortcut.nextPage` | `SPACE` | 下一页 |
| `shortcut.prevPage` | `PAGE_UP` | 上一页 |
| `shortcut.nextChapter` | `CTRL+PAGE_DOWN` | 下一章 |
| `shortcut.prevChapter` | `CTRL+PAGE_UP` | 上一章 |
| `shortcut.toc` | `CTRL+T` | 目录开关 |
| `shortcut.readerPanel` | `CTRL+P` | 阅读设置 |
| `shortcut.immersive` | `CTRL+SHIFT+F` | 沉浸模式（F11 固定为窗口全屏，不占用配置表） |

- 键缺失时读取默认值，无需迁移脚本；用户未改过即为默认行为。

### 3.3 同步格式扩展（`shelf.json`）

- 书架条目新增可选字段 `newChapters`（整数）。
- 读取规则：字段缺失按 0 处理 → 0.7.19 客户端可正常读取新文件；新客户端读旧文件也不报错。
- 冲突规则按 PRD Q-5：同一条目 `updatedAt` 较新者胜；`newChapters` 随条目一起被覆盖，不做逐字段合并。

## 四、关键设计

### 4.1 FR-01 错误分级与失败态

**分类器**（纯函数，便于单测）

```
ErrorKind classify(Throwable e, Context ctx)
  NETWORK      ：SocketTimeoutException / ConnectException / UnknownHostException / IOException 且无解析结果
  SOURCE_RULE  ：AppException 含"解析为空"或"规则"；校验失败阶段=CONTENT/TOC
  CONTENT_MISSING：AppException 含"缺少正文地址"或"章节不存在"
  DATA_DELETED ：AppException 含"书源已被删除"或书籍 deleted
```

**失败态组件 `FailurePane`**

| 组成 | 说明 |
|---|---|
| 主文案 | 按 `ErrorKind` 映射一句话（见 PRD 6.3），不展示异常类名 |
| 动作区 | 1–3 个按钮，按场景传入：重试 / 换来源 / 更新目录 / 先下载 / 校验书源 / 查看信息 |
| 详情折叠 | 默认收起，展开显示原始异常消息、章节序号、书源名，供用户反馈问题 |

**接入点**

1. `ReaderView`：`loadChapter` 的失败回调不再 `setContent(文本)`，改为 `showFailure(chapter, error)`，正文区替换为 `FailurePane`；重试复用当前章节与 `pendingFraction`。
2. `SearchView`：右侧书源进度列表的失败项，增加「重试」按钮，调用 `SearchService` 单源重试（需确认现有 `SearchService` 是否支持单源入口，若不支持则新增 `searchOne(source, keyword)`）。
3. `MainWindow`：侧栏同步卡失败时点击展开 `Alert`（复用 `FailurePane` 结构），提供「重试同步」。

**换来源**：`Book` 目前只有一个 `sourceId`，无多来源记录 → 本期「换来源」仅在 **搜索结果详情** 中可用（同书多源时切换来源加入）；阅读页失败态在无多来源时**不显示该按钮**（不做假按钮）。PRD 已将该限制写为条件行为。

### 4.2 FR-02 更新检查

**服务接口（`application/UpdateCheckService`）**

```
boolean enabled()
long lastCheckAt()
CheckResult runOnce(int maxBooks)   // 串行检查，返回 检查数/有更新数/失败数
int checkOne(Book book)             // 单本：抓目录 → 比对章节数 → 写 new_chapters
void clear(int bookId)              // 读到新章后清标记
```

**执行规则**

| 项 | 规则 |
|---|---|
| 触发 | 主窗口构造完成 5 秒后执行一次（避免与启动同步争抢）；之后由 `Timeline` 每 60 分钟触发 |
| 范围 | `book.source_type='ONLINE' AND deleted=0 AND source_id 有效`，按 `last_read_at` 降序，单轮上限 20 |
| 请求 | 只请求目录页；沿用 `SettingsService.requestInterval()`；并发固定 1 |
| 标记 | 新增数写入 `book.new_chapters`；本轮无变化写 0；失败不修改原值 |
| 清理 | 用户进入该书且读到 `index >= chapterCount - new_chapters` 时清零 |
| 失败 | 不弹窗，只在状态栏累加提示「更新检查：2 本失败」；书源失效的书在书架标记 |

**与既有 `refreshToc` 的关系**：复用 `OnlineBookService.refreshToc`（已实现「补新增章节 + 更新 chapter_count」），`UpdateCheckService` 负责前后计数差与标记写入，避免重复实现目录解析。

### 4.3 FR-03 章节导航

- `ReaderView` 工具条：`← 书架 | ‹ 上一章 | 下一章 › | 书名 | 目录 | Aa`。
- 按钮状态：`updateChapterNav()` 在 `loadChapter` 末尾调用，`index<=0` 禁用上一章，`index>=chapters.size()-1` 禁用下一章，并设 `Tooltip`。
- 点击复用 `previousChapter()` / `nextChapter()`（已存在），保持 350ms 防抖。
- 目录新增「定位当前章」按钮：`toc.scrollTo(index-3)` + `select`，复用 `refreshTocList(true)` 的定位逻辑。

### 4.4 FR-04 沉浸与快捷键

**全屏与沉浸拆开（Q-2）**

| 能力 | 触发 | 实现要点 |
|---|---|---|
| 全屏 | `F11` / 快捷键配置 | `stage.setFullScreen(true/false)`；失败回退「最大化」并提示一次 |
| 沉浸 | 工具条「沉浸」按钮 / 快捷键 | `ReaderView` 隐藏 `toolbar`、`tocBox`、`runningHeader`、`runningFoot`；仅保留正文与右下角页码 |
| 唤出 | 鼠标进入顶部 60px 或 `Esc` | `PauseTransition` 3 秒后再次隐藏；不改变阅读位置与分页 |

**快捷键模型（`ui/Keymap`）**

- 存储格式：`[CTRL+][SHIFT+][ALT+]KEY`，例如 `CTRL+SHIFT+LEFT`、`SPACE`、`PAGE_DOWN`。
- 解析/序列化双向无损；非法格式回落默认值。
- 冲突检测：内置默认表 + 用户覆盖表合并后，两两比较；冲突时阻止保存并提示「与『下一页』重复」。
- 分发：
  - `MainWindow.handleShortcut` 处理全局项（目录、阅读设置、沉浸、全屏）；
  - `ReaderView.handleKey` 处理阅读项（翻页、切章），并保留「焦点在输入框时不拦截」。
- 默认表需保证与 0.7.19 行为兼容：空格/→/↓ 下一页，←/↑/退格 上一页；新增 PageDown/PageUp 切章不再默认占用，避免改变老用户习惯（默认切章用 `CTRL+PAGE_DOWN` / `CTRL+PAGE_UP`）。

### 4.5 FR-05 下载直达阅读

- `DownloadsView`：`table.setRowFactory` 双击打开；右键菜单「阅读」「打开所在章节」；工具条「阅读」按钮。
- 打开逻辑：`ctx.bookService.find(task.bookId)`
  - 找到 → `window.openBookFrom(book, startIndex)`；`startIndex = 有进度 ? progress.chapterIndex : (RANGE 任务 ? fromIndex : 0)`；
  - 未找到（已删除）→ 行置灰、提示「书籍已删除，无法打开」。
- `MainWindow` 新增 `openBookFrom(Book book, int chapterIndex)`，`openBook(book)` 改为调用它并传进度索引，避免两套逻辑。

### 5.2 文案规范（固定，不随意改动）

| 场景 | 文案 |
|---|---|
| 网络失败 | 网络连接失败，请检查网络后重试 |
| 规则失效 | 该书源解析不到正文，可能规则已失效 |
| 内容缺失 | 这一章在源站不存在或地址已变更 |
| 数据被删 | 书源或书籍已被删除 |
| 有更新 | 更新 {n} 章 |
| 已最新 | 已是最新，共 {n} 章 |
| 首章 | 已是第一章 |
| 末章 | 已是最后一章 |
| 快捷键冲突 | 该组合已用于「{动作名}」，请换一个 |

### 5.3 主流程走查（四条，无断点）

1. 阅读 → 章末翻页 → 工具条切章 → 失败 → 重试成功。
2. 启动 → 自动检查 → 书架出现「更新 N 章」→ 读最新章 → 标记清零。
3. 下载页 → 任务完成 → 双击 → 阅读页定位到起始章。
4. F11 全屏 → 沉浸 → 鼠标顶部唤出 → Esc 退出 → 回到原位置。

## 七、兼容、迁移与回滚

| 项 | 方案 |
|---|---|
| 老库升级 | 启动时 `ensureColumn` 补列，默认 0/NULL，无需用户操作 |
| 老设置 | 新键缺失取默认值；不写迁移版本号，避免无谓升级逻辑 |
| 旧客户端读新同步文件 | `newChapters` 为未知字段，Jackson 读取时忽略；不报错 |
| 新客户端读旧同步文件 | 字段缺失按 0 |
| 回滚到 0.7.19 | 新增列不影响旧 SQL（`SELECT b.*` 映射只取已知列）；旧版本忽略新设置键 |
| DB 异常 | 沿用现有策略：初始化失败抛出并提示，不静默丢数据 |

## 九、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 自动更新检查增加请求量 | 书源限流/封禁 | 单轮 20 本、串行、遵守间隔、默认 60 分钟、可关闭 |
| 快捷键与系统/输入法冲突 | 用户按了没反应 | 冲突检测 + 设置页显示当前键位 + 恢复默认 |
| 沉浸模式隐藏元素后无法唤出 | 用户「卡住」 | 顶部热区 + Esc + 任意鼠标移入顶部始终有效 |
| 失败分类误判 | 给错动作 | 分类只依据异常类型与固定文案，未知一律 NETWORK；详情折叠保留原文 |
| 书架标记与同步冲突 | 多端显示不一致 | 按条目 updatedAt 胜出；不同步逐字段 |
| 新增列导致回滚问题 | 旧版异常 | `SELECT b.*` 仅映射已知列；回滚验证纳入用例 |
