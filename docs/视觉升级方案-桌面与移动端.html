纸本 · 朱印

把两端从「软件界面」收拢成一本装帧考究的纸书：暖纸、浓墨、朱砂印，细如发丝的界线与大量留白。 桌面端强调舒展与秩序，移动端强调沉浸与触手可及。两端共用一套颜色、字号与节奏，像同一家出版社出的精装与口袋本。

桌面端 · JavaFX 移动端 · Android 纸白 / 夜间 / 护眼 阅读优先
01 / 设计方向

以「纸、墨、印」建立两端的共同语言

当前的纸白配色方向是对的，但界面仍偏工具：卡片、按钮、标题各自为政，缺少统一的比例与细节。 升级不推翻现有信息架构，而是把颜色、字体、间距、界线收敛为一套可执行的视觉规则，让同一本书在电脑与手机上看起来是同一本。

01

纸感与留白

背景加入极轻的纸纹与暖色偏移；正文两侧留白加大，行距放松。界面留白优先于装饰线，信息靠字号与颜色分层。

02

朱印作为唯一强调色

只在关键动作、当前章节、进度与印章上使用朱砂色；其余全部落在墨色与灰褐之间，避免界面花。
强调色不超过整屏面积的 5%。

03

发丝界线与书脊

用 1px 界线与 2px 书脊替代大块阴影与圆角卡片；列表像书目，阅读页像内页，标题使用楷体或宋体加宽字距。

现状 · 可保留

  • 纸白 / 夜间 / 护眼三套配色与宋体正文
  • 书架卡片、阅读页浮层、目录高亮的结构
  • 桌面端左目录、移动端沉浸阅读

升级 · 统一规则

  • 颜色令牌化：纸、墨、灰、朱、铜五组，三主题共用
  • 字号阶梯：34 / 21 / 17 / 15 / 12 / 10.5，标题加字距
  • 间距：页面 20、列表 16、卡片 8；圆角统一 14
  • 界线替代阴影；书脊色条标识「在读」

B · 阅读页

浮层覆盖，不重排
页脚信息左侧章节名、右侧「页码 · 整书进度」，12px 灰褐；距屏幕底至少 20dp + 6dp 呼吸区，避开手势条。
浮层而非推挤顶部栏与底部面板覆盖在正文上，正文位置不变；面板展开时页脚隐藏，收起后恢复。
底部面板章节滑杆一行，四个入口一行；符号 19px、文字 10–11px，触控高度不小于 44dp。
05 / 组件规范

把细节写成规则

以下规则两端共用；数值以 dp / sp 表示，桌面端按 1:1 映射到 JavaFX。

组件规则说明
页面留白20dp头区、正文、设置卡片左右统一；列表内 16dp
卡片圆角 14 · 间距 8 · 内边距 16/14去掉重阴影，仅保留 1px 界线与一层轻投影

06 / 落地映射

不推翻代码，只替换变量与间距

两端已有主题体系，升级以「令牌 → 组件 → 页面」三步落地，业务逻辑零改动。

层桌面端（JavaFX）移动端（Android）
颜色 src/main/resources/ui/style.css 的 -fx- 变量：-paper、-ink、-accent Ui.Palette：bg / panel / card / ink / muted / accent / line
字号 / 间距 CSS 中的 font-size、padding 统一到 34/21/17/15/12/10.5 与 20/16/8 新增 Ui.SPACE_PAGE / SPACE_LIST / SPACE_CARD / RADIUS_CARD 常量并替换字面量
书架 MainWindow + ShelfView：左书目栏 224px、在读书脊色条 MainActivity：页头 20dp、动作改文字标签、书籍行加编号与细进度线
阅读页 ReaderView：版心 620px、行距 2.1、书眉/页脚 10.5sp ReaderActivity：页脚 12sp、浮层覆盖不重排、安全区保底 20dp
字体 默认京华老宋体；标题可尝试楷体（缺失时回退宋体） 内置宋体/黑体/等宽 + 导入 ttf/otf；标题沿用衬线
07 / 实施顺序

先统一，再精修

按低风险到高收益推进，每一步都可单独验收与回滚。

颜色与字号令牌两端替换变量与字面量，不动布局视觉先统一
桌面端书架与阅读页书案结构、版心、书眉页脚桌面观感提升
移动端书架与阅读页页头、书脊卡片、浮层与页脚细化与桌面同源
细节与回归夜间/护眼校准、对比度、截图验收三主题一致
阅微 · 视觉升级提案 / 纸本 · 朱印 色值、字号与间距均可直接落到现有主题体系
