Desktop audit · before / after

桌面端视觉审查

令牌和配色已经与《视觉升级方案》一致，六页界面却还没有形成同一套气质： 夜间只照亮阅读区、阅读页工具栏过密、设置页缺少页头与分组、搜索 / 下载 / 书源仍是“功能页”。 本稿把六页的现状与建议并排画出来，只做对照，不含代码改动。

Verdict

一套配色，两种性格

已经对齐的是“材料”：纸本朱印的色值、224px 侧栏、980px 内容宽、620px 版心，以及书脊卡片、书眉页脚、目录朱砂竖线。 没对齐的是“结构”：标题层级、动作权重、空状态、表格密度，各页仍按功能自发生长。

01 · 已对齐

材料统一

纸 / 墨 / 灰褐 / 朱砂 / 铜五组令牌，加上 224 侧栏与 620 版心，六页看起来是同一本书的纸。控件也不再回落到 JavaFX 默认外观。

02 · 仍偏离

结构未统一

夜间只作用于阅读区；阅读工具栏 8 个同级文字按钮；设置页没有页头与分组卡；搜索 / 下载 / 书源三页动作同权重、空状态重复。字号阶梯 34 / 21 / 17 / 15 / 12 / 10.5 基本没落地。

03 · 判断

还差一层气质

当前更像“功能页 + 一套阅读皮肤”。提案要的是“书案 / 内页”：页头安静、动作分组、留白大于分隔线。差的不是颜色，是每一页的第一眼焦点。

01

书架

首屏被页头与工具行占满，在读书脊被压到第二屏，且书脊是横排而非竖排。

现状问题

  • 页头五个动作，“刷新”与“同步”语义重叠，和「书架」标题争抢第一眼。
  • 页头下再压一条搜索 / 筛选 / 排序，在读书脊被推到第二屏。
  • 书脊是横排「皓玉」二字，缺少提案里竖排 + 朱砂渐变的实体感。
  • 书目 meta 直接透出「✈ 笔趣中文」与「第 2 / 1141 章」，符号噪声压过书名。

改造建议

  • 页头收敛为问候 + 21px「书架」+ 4 个动作，刷新并入同步或状态栏。
  • 工具行压到 32px、只留搜索与「筛选」气泡，首屏还给书脊。
  • 书脊改竖排、44–48px 宽、朱砂渐变；「继续阅读」改纯文字链接，不带箭头。
  • meta 统一为「作者 · 当前章节名 · 在线阅读 / 已缓存 N 章」，清掉 emoji 与项目符号。
  • 内容区左内边距 20 → 32px，书脊与首行间距 ≥ 24px。
02

阅读

最需要重做：工具栏 8 个同级按钮，正文 28px 像“大字模式”，首段样式未实现。

现状问题

  • 工具栏 8 个同级文字按钮，书名、章节、页码挤在同一行，安静页被破坏。
  • 目录 270px，带搜索框、缓存页脚和「在读」胶囊，信息多于提案。
  • 正文默认 28px / 行距 1.8，提案是 15.5px / 2.15，像大字模式。
  • 所有段落同字号同缩进，提案的首段（无缩进 + 19px 展示字体）没有实现。

改造建议

  • 顶部只留 ← 书架 · 书名（14px 宋体）· 目录 · Aa；上一章 / 下一章 / 着色 / 主题全部收进 Aa 面板。
  • 目录收窄到 236px，去掉「在读」胶囊，当前章只留朱砂文字 + 2px 竖线。
  • 默认改 18px / 2.0（或对齐提案 16px / 2.1），仅对“未自定义”的用户迁移。
  • 首段不缩进、楷体 19px、字距 +0.08em；书眉页脚降到 10.5px、字距 0.12–0.14em。
  • P0：夜间必须扩展到外壳，否则阅读区黑、侧栏亮，永远半张脸。
03

搜索

三块同权卡片 + 三处重复空状态，「加入书架」常态像禁用。

现状问题

  • 书源进度、结果、详情三块卡片都是 14px 圆角，视觉权重完全相同。
  • 空状态在三处重复提示，用户读完仍然不知道下一步该点哪。
  • 搜索框 / 下拉 / 按钮高度不一致；右上角说明与 placeholder 文案重复。
  • 「加入书架」用低对比朱砂实色，无选中时像禁用态故障。

改造建议

  • 主次明确：搜索框 + 搜索按钮为主，书源进度缩为 200px 轻量侧卡，空时折叠成一行。
  • 空状态只留中间一条：一句提示 + 一个动作（去书源页）。
  • 删掉右上角说明文案；所有控件统一 32px 高。
  • 「加入书架」无选中时为普通次按钮，有选中才转朱砂实色。
  • 表头 10 → 11px，行高 36 → 40。
04

下载

1 主 + 8 同权次按钮，「取消」与「刷新」无差别；进度仍是文字。

现状问题

  • 工具栏 1 主 + 8 次按钮，「取消」等危险动作与「刷新」无视觉差别。
  • 「进度」列是文字「成功 693 · 失败 0」，没有用提案的 2px 细进度线。
  • 行没有 hover / selected 态，整张表像静态报表。

改造建议

  • 动作分组：左「新建下载」主按钮；中「暂停 / 继续 / 取消（低饱和警示）」；右「刷新」。
  • 进度列改 2px 细线 + 朱砂填充，数字降为第二行；失败数用赭色小字。
  • 行 hover 用 -card-2，选中用 -card + 左侧 2px 朱砂线。
  • 表头 11px，行高 40。
05

书源

9 个等高同权按钮，名称里带 ✈ 等来源符号，状态列没有颜色语义。

现状问题

  • 9 个按钮等高同权（导入 / 粘贴 / 新建 / 编辑 / 校验 / 删除 / 全部启用 / 全部停用 / 导出），认知负担高。
  • 书源名称保留「✈」等来源符号，破坏文字干净度。
  • 没有按状态 / 分组筛选；表头 10px；状态列缺少颜色语义。

改造建议

  • 工具栏分三组：导入（导入 / 粘贴 / 新建）｜维护（编辑 / 校验 / 导出）｜危险（删除、全部停用收进「更多」）。
  • 名称列去掉 emoji 与前后缀，只留纯文本；分组与兼容性合并成一个 tag。
  • 状态语义色：正常 = 墨绿 / 铜，异常 = 赭，未校验 = 灰褐；表头 11px。
  • 右上统计改为「共 2 · 启用 1 · 异常 1」并支持点击筛选。
06

设置

没有页头与分组卡，整页是一条长表单，最该被突出的预览区反而最不显眼。

现状问题

  • 没有页面标题与说明，直接从「阅读」表单开始，第一眼不知道这是什么页。
  • 整页一条长表单，没有分组卡片，也没有视觉节奏。
  • 字号 spinner、字体 combo、主题 combo、颜色选择器宽度各不相同。
  • 预览区与页面同底色，没有“一张内页”的容器感；开关、色块、样本横向不齐。

改造建议

  • 页头：21px「设置」+ 一句「阅读、标点与网络偏好」；右侧「恢复默认」次按钮。
  • 三张 14px 圆角、1px 界线的分组卡：阅读 / 标点着色 / 网络。
  • 控件统一栅格：标签 96、控件 220、辅助按钮 120，行高统一 32。
  • 预览改为独立卡片（1px 界线 + 24 内边距，背景跟随预览主题），标题放卡片外。
  • 标点规则行固定四列：开关 24 / 名称 110 / 色块 120 / 样本自适应。
Rules

跨页组件规则

六页各自修完之后，仍需要同一套规则兜底，否则下一轮又会分叉。以下八条建议直接写进 style.css。

组件统一规则
次按钮「卡片底 + 1px 界线 + 胶囊」三者齐全。书架与阅读页的纯文字按钮要并入这套语言，不再单独存在。
焦点态保留朱砂 1px 边框，补一层 2px、20% 透明度朱砂外圈，避免只在输入时看到一条细边。
表格表头10 → 11px，字距 0.08em，颜色 -muted；行高 36 → 40。
进度所有进度统一 2px 细线：书架、下载、阅读页页脚共用同一条规则，禁止出现粗条。
空状态「一句主文案 + 一句次文案 + 一个动作」，左右面板不得重复提示。
符号清理书名、书源名中的 emoji；导航提示统一 10px、字距 0.14em。
标题层级落实 34 / 21 / 17 / 15 / 12 / 10.5：页面标题 21、卡片标题 15、表头 11、辅助 10.5。
夜间主题令牌必须注入主窗口根节点，覆盖侧栏、状态栏、对话框；不允许只覆盖阅读区。
Priority

按气质排序，不按工作量排序

P0 决定这套界面能不能被认成「一本书」；P1 决定它有没有「书案」感；P2 只做精修，不改变结论。

P0 · 气质

先做三件

  1. 夜间令牌扩展到主窗口外壳，侧栏与状态栏同步变深。
  2. 阅读页工具栏精简为「返回 / 书名 / 目录 / Aa」，其余收进 Aa 面板。
  3. 阅读默认字号、行距、首段样式对齐提案，仅迁移未自定义的用户。
P1 · 书案

再做三页

  1. 设置页加页头与三张分组卡，预览独立成卡。
  2. 书架页头收 4 个动作、工具行降噪、书脊竖排。
  3. 搜索 / 下载 / 书源：动作分组、空状态合并、表头字号。
P2 · 精修

最后统一

  1. 表格 hover / selected 令牌化。
  2. 进度线统一为 2px。
  3. emoji 清理、焦点外圈、字距归位。
