# 阅微阅读器 v0.2 功能规格：排版、图标与安装包

配套文档：[PRD-小说阅读器.html](./PRD-小说阅读器.html)、[开发流程.md](./开发流程.md)

## 需求定位

| 维度 | 结论 |
|---|---|
| 需求类型 | 小版本功能迭代 |
| 复杂度 | 轻量（1–3 页） |
| 读者 | 工程实现与验收 |
| 风险等级 | 低（仅影响阅读样式与分发，不改动书籍、书源、进度数据） |

触发来源：阅读页只能调整字号，字体固定为系统默认，行距参数在设置页存在但无法预览；同时应用没有窗口图标，也没有可分发的安装包。v0.2 补齐这四项，让阅读排版可配置、可即时验证，并产出可安装的 Windows 程序。

## 目标用户与场景

使用者在长时间阅读时，会因字体字形、行间距不合适而疲劳；换设备或重装系统后，希望用安装包一次装好，而不是手工配置 Java 环境。对应两个场景：阅读中随手调整排版，调整后立刻看到效果；从安装包安装后，桌面与开始菜单出现带图标的程序入口。

## 功能需求

### FR-1 系统字体选择

设置页的字体下拉列出操作系统已安装的全部字体（`Font.getFamilies()`），首项为“系统默认”。下拉列表中每个字体名以该字体本身渲染，便于直观比较。阅读页工具栏新增“排版”，可直接切换字体、字号与行距，无需离开正文。

选择的字体写入 `reader.fontFamily`，重启后保持。字体不存在时回退到系统默认，不阻断阅读。

### FR-2 行距调整

行距以倍数表示，范围 1.2–3.0，步长 0.1，写入 `reader.lineSpacing`。行距通过 `TextFlow.setLineSpacing` 作用于正文，实际行间距为 `(倍数 - 1) × 字号`，与阅读页和预览保持一致。

设置页新增实时预览区，字体、字号、行距、主题四项变化立即反映在预览中；保存后阅读界面同步刷新，不再需要重新打开书。

### FR-3 应用图标

同一视觉标识生成 16/32/64/128/256 五种尺寸 PNG，用于窗口与任务栏；安装包与快捷方式使用多尺寸 ICO。图标为深绿圆角底、翻开的书页与书签，小尺寸下轮廓仍可辨认。

图标资源位于 `src/main/resources/icon/`，安装包图标位于 `packaging/app.ico`。

### FR-4 Windows 安装包

使用 JDK 17 的 `jpackage` 生成两类产物：内置精简运行时的免安装目录，以及 exe 安装包。安装包提供桌面快捷方式、开始菜单项、安装目录选择，按当前用户安装，不需要管理员权限。安装后数据仍保存在 `%USERPROFILE%\.yuewei-reader`，与免安装运行共用同一份书架与设置。

版本号提升到 0.2.0，安装包保留升级 UUID，后续版本可覆盖升级。

## 交互约定

阅读页工具栏顺序：返回书架、书名、章节名、上一章、下一章、目录、字号减、字号加、排版、主题、进度。排版弹窗内调整即生效并自动保存，关闭弹窗即可；弹窗提供“恢复默认”（系统默认字体、18 号字、1.8 倍行距）。

设置页保存时提示改为“阅读样式已立即应用到阅读界面”，避免用户误以为需要重启。

## 验收标准

| 编号 | 操作 | 期望结果 |
|---|---|---|
| AC-1 | 打开设置页 | 字体下拉包含系统已安装字体，数量与系统字体一致，首项为“系统默认” |
| AC-2 | 选择“楷体”，观察预览 | 预览文字立即变为楷体；保存后阅读页正文同步为楷体 |
| AC-3 | 行距从 1.8 调到 2.4 | 预览与正文行间距同时变宽，滚动位置不丢失 |
| AC-4 | 阅读页打开“排版”并修改字号 | 正文立即变化，退出重进后仍保持 |
| AC-5 | 查看窗口与任务栏 | 显示书本图标，任务栏缩略图不再使用 Java 默认图标 |
| AC-6 | 运行安装包 | 可选择目录、创建快捷方式，安装完成后可启动并读到已有书架 |
| AC-7 | 安装后检查数据目录 | 仍为 `%USERPROFILE%\.yuewei-reader`，原有书籍与进度可读 |

## 边界与非目标

不支持导入字体文件，字体来源限定为系统已安装字体；不支持分页模式与自定义段间距；安装包仅面向 Windows x64。Linux 与 macOS 的打包不在本版本范围。
